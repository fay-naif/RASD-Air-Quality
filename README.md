## الهدف والبيانات

يستخدم المشروع بيانات محطة Aotizhongxin الحقيقية من مجموعة Beijing Multi-Site Air Quality الخاصة بـ UCI للفترة 2013–2017، محفوظة في `data/air_quality.csv`.

يستخدم نموذج التصنيف الخصائص المباشرة وإشارات تاريخ ووقت القراءة. ولا يستخدم التأخرات أو المتوسطات المتحركة.

## التصنيف

المتغير المستهدف هو PM2.5 بعد ساعة واحدة، موزعًا إلى:

- منخفض: ≤12 ميكروغرام/م³
- مرتفع قليلاً: >12 و≤35.4
- مرتفع: >35.4 و≤55.4
- مرتفع جدًا: >55.4

النموذج هو Logistic Regression بترجيح الفئات داخل Pipeline يتضمن تعويض القيم الوسطي وتوحيد المقياس. تُجمع الميزات من القراءات الحالية والسابقة والإشارات الزمنية فقط.

## منع التسرب والتقييم

التقسيم زمني: 70% تدريب، 15% تحقق، 15% اختبار معزول. لا تستخدم قيمة الساعة التالية ضمن المدخلات، ولا تتعلم المعالجة على بيانات التحقق أو الاختبار.

تُحسب قيم التعويض الوسيطية حصراً من مجموعة التدريب: 23,317 ساعة. الخانات الزمنية لا تُعوّض بالوسيط؛ تُحسب من تاريخ ووقت القراءة المدخلين صراحةً.

نتائج تصنيف الاختبار الفعلية المعزولة زمنيًا:

- الدقة الكلية: 79.69%
- الدقة المتوازنة: 77.96%
- Macro F1: 74.08%
- عينة التدريب: 23,317 ساعة
- عينة التحقق: 4,997 ساعة
- عينة الاختبار: 4,997 ساعة

تُحفظ المقاييس في `results/classification_metrics.json`.

يعتمد نموذج التصنيف المحدث على القراءات المباشرة والإشارات الزمنية للساعة والشهر فقط؛ ولا يستخدم التأخرات أو المتوسطات المتحركة.

يقيس نموذج التنبؤ العددي الموجود MAE وRMSE وR² على الاختبار المعزول؛ تُقرأ هذه الأرقام من `results/metrics.json` ولا توجد نتائج منفصلة قديمة في واجهة التطبيق.

الفئات حدود توضيحية وليست مؤشر جودة هواء رسميًا أو نصيحة صحية.

## التشغيل

```powershell
python -m pip install -r requirements.txt
python train_classification.py
python -m streamlit run app.py
```

## البنية

- `app.py`: واجهة Streamlit ثنائية اللغة.
- `core.py`: تحميل البيانات والمعالجة والميزات والفئات.
- `train_classification.py`: تدريب التصنيف وتصدير المقاييس.
- `data/`: البيانات التاريخية الفعلية.
- `results/model.joblib`: نموذج التنبؤ العددي السابق.
- `results/classification_model.joblib`: نموذج التصنيف المقيّم زمنيًا.
- `results/classification_metrics.json`: مقاييس التصنيف الفعلية.
- `.streamlit/config.toml`: المظهر الفاتح والداكن.
- `RASD.ipynb`: دفتر التحليل السابق.

## التقنيات

Python وPandas وNumPy وscikit-learn وStreamlit وJoblib.
